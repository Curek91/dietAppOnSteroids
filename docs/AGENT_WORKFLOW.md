# Agent Workflow

We use three agents working in parallel.

Agents:
1. Architect Agent
2. Full Stack + Mobile Developer Agent
3. Product Designer / UX / UI / Storytelling Agent

Parallel work rules:
- Architect owns architecture and task boundaries.
- Developer owns implementation.
- Designer owns UX, UI, copy and design system.
- Agents must not overwrite each other's work without reason.
- Large changes require updating docs first.
- Every feature should be small, testable and shippable.

Recommended flow:
1. Architect defines structure and task.
2. Designer defines UX/UI behavior.
3. Developer implements.
4. Architect reviews.
5. Designer polishes.
