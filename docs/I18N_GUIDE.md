# I18N Guide

Supported locales:
- pl-PL
- en
- en-GB
- en-US
- fr-FR
- de-DE
- nl-NL
- it-IT
- zh-CN
- ar-AE

Rules:
- No hardcoded user-facing text.
- All text must go through translation files.
- Use simple translation keys.
- Keep copy short and clear.
- Design must support longer German/French text.
- Arabic must support RTL layout.
- English can be default fallback.
